KotaHub Fitbit Trial

KotaHub Fitbit Trial is a personal, single-user application maintained by the account owner for private use. It reads the owner's own Fitbit health and fitness data through the Google Health API (read-only) and stores it in a private local database so the owner can review personal trends such as steps, sleep, resting heart rate, heart rate variability, blood oxygen saturation, and weight.

The application is not offered to the public, has no other users, and does not sell, share, or publish any health data. Data is never transferred to third parties.

See the Privacy Policy for details on what data is accessed, how it is stored, and how it can be deleted.
